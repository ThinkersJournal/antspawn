## Design decisions (PM-approved 2026-10-21)
1. JobSpec TOML (strict): `[job]` name/cmd/cwd/env/secrets, `[[mount]]` ro|rw|scratch, `[limits]`, `[needs]`
   network/gpu/tools/require/prefer, `[[output]]`.
2. Needs = capability set (`isolation.no-read-outside`, `isolation.no-write-outside`, `clean-slate-next-run`,
   `kills-runaway-process`, `network.off`, `gpu.cuda`, `gpu.vulkan`, `concurrent`); order = `prefer`.
3. `Launcher::provision -> Environment { run, collect, destroy }`, destroy also on Drop.
4. `Registry::providers` (unmet named, no closest match) and `open_named` (re-checks the matrix).
5. Matrix = PersistAnt's nine-column TSV in `matrix/`, own parser, generated by `cargo run --example matrix`,
   committed, CI diffs it.
6. Launchers slice 1: `account` (PRE-PROVISIONED restricted account, never created or elevated by us; loud error if
   absent; ACL deny on C:\Projects; wiped work dir; Job Object kill-on-close) and `windows-sandbox` (.wsb with
   mapped folders, logon command, poll results, close).
7. Negative controls per launcher: read `C:\Projects` must FAIL; file left behind is gone next run; forked survivor
   is killed. A `naive` launcher (plain child process) must FAIL them, proving the tests bite.
8. CLI: `spawn run <spec> [--launcher id] [--results dir]`, `spawn providers <spec>`, `spawn matrix`, `spawn check <spec>`.
9. CI runs types + parser + `naive` on windows-latest and ubuntu. Privileged tests are runner-only, NAMED UNVERIFIED
   until a runner exists (board decision 241 for a public repo), never `#[ignore]`; run them locally and record
   results in `docs/MEASUREMENTS.md` (date, ref).
10. `secrets[]` = names only, resolved at run time, never logged or written to env/files; none implemented (spec refused).
