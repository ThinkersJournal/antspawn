## Ideas swept

1. **Needs matched to capabilities that tests earned.** A job declares a set of needs (isolation, clean slate, kill-runaway, network off, GPU); a launcher counts as providing a capability only when a committed matrix row says `yes`, the matrix being generated by running the tests; an unmet need names the closest launcher instead of running.
2. **A known-bad control per isolation test.** Every test also runs against a deliberately naive launcher (a plain child process) and must FAIL there, so a test that cannot fail is caught.
3. **A restricted pre-provisioned OS account launcher.** The job runs as a restricted account that was set up once, separately, and is never created or elevated by the runner; an ACL denies the account the portfolio tree; the working directory is wiped; a Job Object kills the process tree on close.
4. **A disposable Windows Sandbox VM per job.** The host starts the sandbox with the `wsb` command-line tool, maps declared folders (read-only, read-write, scratch), runs the job by a logon-time command, polls for result files, collects declared outputs and closes the VM.
5. **One-shot delivery of a single-use CI runner configuration into a fresh VM.** A guest listener binds, accepts exactly one connection, closes the listener before reading, and starts the runner with the value in that child's environment only; the host finds the guest address, connects with retry, sends once and closes. Never a file, argument or inherited variable.
6. **One runner VM per queued CI job.** A watcher polls the forge for queued jobs, mints a just-in-time runner configuration, starts one VM (busy until it ends), the runner takes one job, the VM is destroyed.
7. **Secrets named, not carried.** A job spec lists secrets by name only; none is resolved today, and a spec listing one is refused.
8. **Environments destroyed on every exit path.** An environment object whose destroy also runs on drop, so a crashed run does not leave a VM or directory.

## Open points and watches

- **Re-sweep before** adding a one-time-token handshake or a request/validate step to the JIT listener (hit 1), writing the JIT value to a file (hit 2), or pre-creating VMs / a warm pool / a golden-image pre-start (hit 3).
- Re-sweep when a capability family is added (for example GPU, Sandboxie, or any resolved secret), and at least yearly once released.
- The Espacenet, USPTO and WIPO gaps above stay open; a stronger search should precede the first publish.
